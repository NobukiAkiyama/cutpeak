# Occamusを参考にしたUI再設計

2026-09-05。ユーザーが選択した参考: [Occamus Video Editor / Vladimir Palyanov](https://dribbble.com/shots/15933480-Occamus-Video-Editor-FREE)、[Figma Community](https://www.figma.com/community/file/991274033166018675)。

作者の公開画像で、黒い作業面、紫の主要操作、黄色のトリム枠、紫の音声波形、角丸の素材カード、下部の編集ツールを確認しました。元のデザインはモバイル向けです。Figmaファイル自体を複製せず、これらの視覚的特徴をFramecutのデスクトップ／タブレット用レイアウトに適用しています。作者のデモ画像・イラストはアプリに組み込んでいません。

- 左の縦型ツール列を下部の横型ドックへ移動。
- 分割・削除・複製・スナップをタイムラインの下に配置。
- クリップを選択していない間は右のインスペクターを閉じ、プレビューを拡大。
- 素材カード、主要ボタン、プレビュー、ダイアログの角丸と余白を統一。
- 操作は紫、選択と再生位置は黄色、音声クリップは紫で区別。
- 狭い画面ではプレビュー＋タイムラインを中心にし、素材パネルと編集シートを必要に応じて表示。

変更は表示とレイアウトが中心です。既存の動画処理・保存・履歴モデルは変更していません。実ブラウザによる操作テストと画面の自動比較は未実施です。
