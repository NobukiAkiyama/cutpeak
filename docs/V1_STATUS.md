## 実施済み

- 57件の自動テスト（モデルと編集、履歴分岐、補間、SRT、音量、PCM WAVの実デマックスとデコード、リサンプル・ミックス、LRU、保存世代、フォールバック、書き出し形式の能力判定、再生準備中の中止、Driveの条件付き更新・競合・アップロード再開、履歴パック）。
- TypeScript の型チェックとプロダクションビルド。
- Oxlint によるコードの静的検査。
- 依存関係の監査。実装時の最終監査では既知の脆弱性0件。
- 開発サーバーのHTTP応答。UIの手動・自動操作を使うブラウザE2Eテストは実施していません。

## 未検証と制約

- **動画の実エンコード／デコード、WebGL表示、映像と音声の同期、各ブラウザの動作**は、実ブラウザでのE2E検証が必要です。MP4/MOVのコンテナ対応と、端末が持つコーデックの対応は別です。
- **Google Driveの実認証・通信は未検証**です。OAuth Client ID・API Key・App IDは利用者のGoogle Cloud設定が必要です。モックテストは実Google APIでの成功の代替にはなりません。
- 実端末でのSafari/iPad/Android/Firefoxのタッチ操作、メモリー制限、コーデック差は未検証です。
- PWAのキャッシュ生成は実装済みですが、Service Workerを使う実ブラウザでのオフライン受け入れ試験は未実施です。開発サーバーではService Workerを登録せず、`npm run build` 後の配信で有効にします。
- OPFS非対応の互換モードはセッション素材の再読み込み後の復元を保証しません。OffscreenCanvas非対応ではメインスレッドでのメディア処理・描画・書き出しに退避し、性能が低下する可能性があります。
- 各コミットはプロジェクト状態を保持します。素材バイナリは共有しますが、大量の履歴の圧縮・GC、プロキシ生成、長時間4Kの性能調整は今後の作業です。フレームLRUは64MiBを基準に制限します。
- 一般的な分割・移動の履歴差分は説明文にしています。複雑な複数プロパティ比較の専用比較画面やMerge UIはありません。
- WebMCPの読み取り・分割ツールを機能検出して登録します。対応する実行コンテキストでの登録・呼び出し検証は未実施です。未対応ブラウザではこの機能を利用しません。
- V1.5/V2のクロマキー、速度変更、自動字幕、AI編集、共同編集などは対象外です。

## 実ブラウザでの受け入れ確認

1. 短いH.264/AACのMP4、PNG、WAV、SRTを読み込む。
2. 分割・トリムし、音声を重ね、字幕と画像をプレビュー上で移動する。
3. 先頭と末尾でキーフレームを設定し、再生・シーク・Undo/Redoで確認する。
4. ページを再読み込みして素材・履歴・別案が復元されることを確認する。
5. MP4とWebMを書き出し、別プレイヤーで映像、音声、尺、字幕、変形を確認する。
6. 本番ビルドを一度開いた後、オフライン状態で起動・編集・保存・書き出しを確認する。
7. Google設定後、Portable保存、別端末での読み込み、同時編集の競合、通信断後のアップロード再開を確認する。
